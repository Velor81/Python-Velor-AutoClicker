# 🖱️ Auto Clicker (Keyboard and mouse)
A professional automation tool built with **Python**.

![App Screenshot](Screenshot.PNG)

🚀 Advanced Task Automation (More than just a clicker!)
Unlike standard clickers, Velor Auto Clicker allows you to build complex sequences of actions. You can:
Custom Sequences: play back a mix of mouse clicks and keyboard presses.
Mouse Actions: Supports Left Click, Right Click, and even Hold duration (e.g., hold for 2.0s).
Keyboard Support: Simulate typing any key as part of your automation routine.
Smart Delays: Add custom wait times between each specific action, not just a global speed.
Fully Editable List: Reorder actions (Move Up/Down) or delete specific steps to fine-tune your macro.
Toggle Keys: Set your own custom Hotkey (like F8) to start/stop the entire sequence instantly.
