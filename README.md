# 🖱️ Velor Auto Clicker (Keyboard and mouse)

A free, open-source, portable auto clicker and macro tool for Windows.

## Features
- Mouse Click & Hold
- Keyboard Press & Hold
- Custom Delays
- Save & Load Macros
- Global Hotkey (F8)
- Portable
- No Ads
- Open Source
