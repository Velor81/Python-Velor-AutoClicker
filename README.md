# Velor Auto Clicker

A free, open-source, portable **Auto Clicker** and **Keyboard Automation** tool for **Windows**.

Velor Auto Clicker lets you create simple mouse and keyboard macros with customizable delays. It is lightweight, easy to use, requires no installation, and contains no advertisements.

## Features

- 🖱️ Mouse Click & Hold
- ⌨️ Keyboard Press & Hold
- ⏱️ Custom Delays
- 💾 Save & Load Macros
- 🎯 Global Hotkey (F8)
- 📦 Portable (No Installation Required)
- 🚫 No Ads
- 🔓 Open Source (MIT License)
