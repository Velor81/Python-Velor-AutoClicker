🚀 Advanced Task Automation (More than just a clicker!)
Unlike standard clickers, Velor Auto Clicker allows you to build complex sequences of actions. You can:
Custom Sequences: play back a mix of mouse clicks and keyboard presses.
Mouse Actions: Supports Left Click, Right Click, and even Hold duration (e.g., hold for 2.0s).
Keyboard Support: Simulate typing any key as part of your automation routine.
Smart Delays: Add custom wait times between each specific action, not just a global speed.
Fully Editable List: Reorder actions (Move Up/Down) or delete specific steps to fine-tune your macro.
Toggle Keys: Set your own custom Hotkey (like F8) to start/stop the entire sequence instantly.

=======
A lightweight, professional automation tool for Mouse & Keyboard sequences.
✨ About the Project
Built for personal use and as a learning milestone in Python and PySide6.
⚠️ Note: This project will not receive further updates.
🚀 Key Features
Advanced Macros: Combine mouse clicks (Left/Right/Hold) and keyboard presses in one sequence.
Fully Editable: Reorder actions (Move Up/Down) or set custom delays between steps.
Responsive UI: Multi-threaded design to ensure the GUI remains fluid during automation.
Hotkeys: Set custom keys (e.g., F8) to Start/Stop sequences instantly.
Portable: Single .exe file; no installation required.
🛠️ Tech Stack
Language: Python
UI: PySide6 (Qt)
Libraries: pynput, pyautogui
Build Tool: auto-py-to-exe
